# 物流 SaaS UI 设计素材说明

本目录用于存放 Transix 物流 SaaS 平台的设计素材，包括：

## 建议存放的素材类型

### 1. 截图文件
- `landing_page.png` - Landing Page 完整截图
- `dashboard.png` - Dashboard 看板截图
- `typography.png` - 字体规范展示图
- `mobile_responsive.png` - 移动端适配展示图
- `components.png` - 组件库展示图

### 2. 设计源文件（可选）
- `transix_design.fig` - Figma 设计文件
- `color_palette.sketch` - Sketch 配色方案
- `icons.svg` - 图标集合

### 3. 字体文件（如需本地使用）
- `Inter-Regular.woff2`
- `Inter-Medium.woff2`
- `Inter-SemiBold.woff2`
- `Inter-Bold.woff2`

### 4. 图标资源
- `/icons/` - 图标文件夹
  - `home.svg`
  - `truck.svg`
  - `package.svg`
  - `chart.svg`
  - `settings.svg`

## 获取素材的方式

### 方式 1：从 Behance 下载
访问原始设计页面：
https://www.behance.net/gallery/249758629/Transix-Logistics-SaaS-Landing-Page-UI-UX-Design

### 方式 2：从语雀文档获取
参考链接中的截图和设计稿

### 方式 3：自行创建
根据 SKILL.md 和 references/design_assets.md 中的规范自行创建设计素材

## 注意事项

- 素材文件不应过大（单张图片 < 5MB）
- 使用常见的图片格式（PNG、JPG、SVG、WebP）
- 保持文件名简洁且有描述性
- 如有版权限制，请遵守相关许可协议

## 当前状态

本目录为占位符，实际使用时可根据需要添加具体素材文件。
